# Rongfeng Cheng CVs

The English CV is typeset with the open-source [ModernCV](https://github.com/moderncv/moderncv) LaTeX class using the `banking` style. The Chinese academic CV uses a custom XeLaTeX layout.

## Build

A TeX Live installation with ModernCV is required.

```bash
xelatex rongfeng-cheng-cv.tex
xelatex rongfeng-cheng-cv.tex
xelatex rongfeng-cheng-cv-zh.tex
xelatex rongfeng-cheng-cv-zh.tex
```

The website serves the generated PDF from:

```text
public/cv/cheng-rongfeng-cv.pdf
public/cv/cheng-rongfeng-cv-zh.pdf
```
