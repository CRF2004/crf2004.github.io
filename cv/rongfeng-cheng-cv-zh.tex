\section{核心科研经历}
\project{DLEF: Dataset-Label Evidence Fingerprints for Explaining Cross-Dataset Performance in ECG Classification}{2026.06--至今}{第一作者｜指导：张浩彬、程伟彬｜IEEE BIBM 2026 在审}{
\begin{itemize}
  \item \textbf{本人工作：}提出研究问题并主导研究设计、代码实现、实验分析与论文撰写；构建方向性证据指纹，刻画数据集--标签层面的迁移风险。
  \item \textbf{主要结果：}在 CODE-15\%、PTB-XL、Chapman-Shaoxing 三个数据集上验证；DLEF 距离与标签级外部 AUROC 下降显著相关（108 个点 Spearman $r=0.843$；聚合后 $r=0.892$）。
  \item \textbf{研究意义：}将“模型跨数据集性能下降”进一步拆解为可解释的标签级证据差异，为迁移风险审计提供可复核指标。
\end{itemize}}

\project{A Matched-Control Perturbation Audit Framework for Evaluating Evidence Use in Deep Learning Models: An Application to 12-Lead ECG Classification}{2026.01--至今}{第一作者｜指导：张浩彬、程伟彬｜IEEE JBHI 在审}{
\begin{itemize}
  \item \textbf{本人工作：}从早期负结果中提出审计问题，主导 matched-control 扰动框架、临床证据单元、算子比较、冻结权重外部迁移及论文写作。
  \item \textbf{主要结果：}在 CODE-15\% 与 PTB-XL 上评估 5 类诊断和 3 种原始信号模型；15 个模型--诊断组合中仅 6 个获得证据支持，并对各个审计结论进行了根因分析。
  \item \textbf{研究意义：}模型对证据的依赖往往跨数据集迁移稳定；仅扰动目标区域可能产生误导；matched controls 和算子选择能够改变证据使用结论，外部性能良好也不等于模型依赖预设临床证据。
\end{itemize}}

\project{PathCLIP: Evidence-Aware ECG--Text Representation Learning}{2026--至今}{第一作者研究｜进行中}{
围绕 ECG--文本对齐与零样本识别，设计 matched-count、层级置乱、残差单独输入和未见标签等对照，探索从“审计模型使用了什么证据”进一步走向“训练模型学习可靠证据”。}
